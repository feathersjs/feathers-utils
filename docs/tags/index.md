# Tags

`category` tells you the *shape* of a utility — whether it is a hook, a plain
util, a predicate. Tags tell you what it is *for*, and they cut across every
category: the answer to "how do I change the query before it hits the adapter?"
is a hook in one case and a util in the next.

The vocabulary is closed and deliberately small, so a tag stays useful as a
filter. Pick one to see everything carrying it, or filter the
[hooks](/hooks/) and [utilities](/utils/) tables directly.
